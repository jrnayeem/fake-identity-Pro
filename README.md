# FakeNames

    Fake identity generator supporting 30+ countries.

    ## Deploy to Netlify

    ### Option A – Drag and drop
    Drag this zip onto **netlify.com/drop** — Netlify builds it automatically.

    ### Option B – Manual
    ```bash
    npm install
    npm run build   # outputs to dist/
    ```
    Then deploy the `dist/` folder.

    ### Option C – Connect a repo
    Push the extracted folder to GitHub and connect it on Netlify.
    Build command: `npm run build`
    Publish directory: `dist`
